General

Open in browser opens at its own size

The arrow on each panel's label opens that panel's page here, at the panel's width, so you can use that browser's own developer tools.

The Inspect button next to it is always WebKit's Web Inspector, and cannot be changed. A panel is a WKWebView, which is the only engine available on macOS, and Chrome DevTools has no way to attach to one. That is what this setting is for.

Agent bridge

A local server that lets Claude Code or Codex see every panel, run JavaScript in them, and read what the scan found. It listens on 127.0.0.1 only and is off until you turn it on.

Break/Points

Your code knows your breakpoints. Break/Points reads them out of the project and builds the testing environment from what it finds.

Panels render at the exact breakpoint width, which is the first pixel of the range and where layouts actually break. Heights come from the aspect ratio of a real device in that size class. Every number on screen is the true one, including the scale percentage when a panel is shrunk to fit.
